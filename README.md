## 🌟 Overview

Official portfolio website of **Yazan Gupta**, Full-Stack Web Developer and B.Tech Computer Science & Data Science student at Echelon Institute of Technology (2024–2028). 

Engineered with a **Liquid-Glass Obsidian** aesthetic, dynamic 2D canvas starlight physics, and serverless microservices backed by **MongoDB Atlas**.

---

## ⚡ Technology Breakdown

| Category | Technology | Usage in Project |
| :--- | :--- | :--- |
| **Frontend Framework** | **React 19** (`v19.2.8`) | Core UI component hierarchy, hooks, state management |
| **Build Tool & Bundler** | **Vite 8** (`v8.3.0`) | Lightning-fast HMR and optimized production bundling |
| **Routing & Code-Splitting** | **React Router v7** (`v7.18.4`) | Client-side SPA navigation with `React.lazy()` & `Suspense` |
| **Styling & Design System** | **Tailwind CSS v3** (`v3.4.17`) | Utility-first responsive styling & custom liquid-glass tokens |
| **Motion & Micro-Interactions** | **Framer Motion 14** (`v14.2.0`) | Smooth spring transitions, scroll reveals, and modal animations |
| **Backend & Microservices** | **Node.js + Vercel Serverless** | Serverless API routes (`/api/projects`, `/api/download-resume`, etc.) |
| **Database & Analytics** | **MongoDB Atlas & Mongoose** | Dynamic project caching and live resume download telemetry |
| **Visual Effects Engine** | **HTML5 2D Canvas** | 60fps ambient starlight, shooting meteors, and particle physics |
| **SEO & Standards** | **Schema.org JSON-LD** | Google Knowledge Graph entity mapping and Rich Sitelinks |

## 📄 Pages & Architecture

- 🏠 **Home (`/`)**: Hero banner with 3D YG brand emblem, live availability indicator, quick stats, and featured projects.
- 👨‍💻 **About (`/about`)**: Background journey, academic records, core competencies, and dedicated **Hobbies & Interests** (featuring active Stock Market Trading with Bull vs Bear artwork).
- ⚡ **Skills (`/skills`)**: Categorized technical skills matrix covering Frontend, Backend, Database, Cloud & DevOps, and Core CS.
- 💼 **Projects (`/projects`)**: Production project showcase highlighting **SevaSetu** with live image carousels, feature checklists, and live links.
- 📜 **Certifications (`/certifications`)**: Interactive certificate gallery with full-resolution credential inspection modals.
- 💼 **Experience (`/experience`)**: Chronological timeline of engineering experience, education milestones, and competitions.
- 📬 **Contact (`/contact`)**: Functional contact form, instant WhatsApp chat trigger, direct email, and social networks.

## 🏃 Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/yazantechofficial89/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Local dev server runs at: `http://localhost:5173`

```bash
# Build for production
npm run build
```
