# 🚀 Multi-Page Full-Stack Developer Portfolio

An ultra-modern, responsive, multi-page portfolio website built with **React 19**, **React Router v7**, **Tailwind CSS**, and **Framer Motion**.

---

## 📄 Pages Included

- 🏠 **Home (`/`)**: Hero section, quick facts, top skill highlights, featured project cards, terminal teaser, and hire CTA.
- 👨‍💻 **About (`/about`)**: Detailed background story, engineering philosophy, 3 technical pillars, quick facts, and resume download.
- ⚡ **Skills (`/skills`)**: Filterable technology matrix (Frontend, Backend, Database, DevOps & Tools), proficiency meters, and architectural standards.
- 💼 **Projects (`/projects`)**: Production project showcase with real-time search, category filters, tags, feature checklists, and live/code links.
- 📜 **Experience (`/experience`)**: Chronological career & education timeline, milestones, and resume download.
- 💻 **Terminal (`/terminal`)**: Dedicated interactive developer CLI shell with custom commands (`help`, `about`, `skills`, `projects`, `contact`, `sudo hire`).
- 📬 **Contact (`/contact`)**: Contact form with instant status, direct email & phone calling cards with one-click copy, social channels, and FAQs.
- 🧭 **404 Not Found (`*`)**: Sleek fallback page with a link back home.
